## REST API vs RESTful API

### 1️⃣ REST API (Representational State Transfer API)
- यह एक **आर्किटेक्चर स्टाइल** है जो API को डिज़ाइन करने के लिए इस्तेमाल होता है।  
- इसमें **HTTP मेथड्स** (GET, POST, PUT, DELETE) का उपयोग किया जाता है।  
- यह **Stateless** होता है, यानी हर रिक्वेस्ट को अलग से हैंडल किया जाता है।  
- JSON या XML डेटा फॉर्मेट में कम्युनिकेशन होता है।  

#### Example:
```
GET https://api.example.com/users
```
यह API सभी **users** की लिस्ट देगा।  

---

### 2️⃣ RESTful API
- यह **REST API का एक सही Implementation** है।  
- REST के सभी **रूल्स** को फॉलो करता है।  
- **Scalability** और **Efficiency** पर ध्यान देता है।  
- URL को **Resources** की तरह ट्रीट करता है।  

#### Example:
```
GET    /users       → सभी यूजर्स की लिस्ट  
GET    /users/1     → यूजर 1 की डिटेल्स  
POST   /users       → नया यूजर जोड़ना  
PUT    /users/1     → यूजर 1 को अपडेट करना  
DELETE /users/1     → यूजर 1 को डिलीट करना  
```

---

### **मुख्य अंतर**
| **Feature**  | **REST API**  | **RESTful API**  |
|-------------|--------------|------------------|
| परिभाषा | एक आर्किटेक्चर स्टाइल | REST के नियमों को सही से लागू करता है |
| नियमों की पाबंदी | कोई भी API REST स्टाइल में हो सकती है | पूरी तरह से REST के नियमों को फॉलो करता है |
| Scalability | जरूरी नहीं | अधिक स्केलेबल और ऑप्टिमाइज़्ड |
| Stateless | हां | हां | 

---

👉 **सीधे शब्दों में:**  
REST API एक **कॉन्सेप्ट** है, और अगर API REST के सभी रूल्स को पूरी तरह से फॉलो करती है, तो उसे **RESTful API** कहते हैं। 🚀
